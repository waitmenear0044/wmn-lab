# wmn-lab.ru

Личный сайт-сборник: промпты, гайды, маленькие инструменты и прочие приколы.
Дизайн — домашняя страничка раннего интернета (окно Win98, WordArt, кнопки 88×31) в современной вёрстке.

**Технологии:** чистый HTML + CSS + JavaScript. Без фреймворков и без сборки: файлы заливаются на сервер как есть.

---

## Структура

```
index.html              главная
404.html                страница «не найдено»
assets/
  css/base.css          ВЕСЬ дизайн: цвета, шрифты, окно, кнопки
  js/site.js            ВСЁ общее: список разделов, меню, шапка, футер
  js/games.js           игры из меню «Игры»
  img/                  картинки, превью для соцсетей, иконки
data/news.json          лента «Что нового» на главной
prompts/
  index.html            страница раздела
  prompts.json          все промпты, сферы и задачи
  prompts.js            рабочий стол, окна, поиск, корзина
dough/
  index.html            страница калькулятора
  recipes.json          рецепты
  dough.js              логика пересчёта
bot/index.html          страница бота + мем-генератор
  meme.js, phrases.json   логика генератора и фразы
lab/index.html          песочница для черновиков (не в меню, закрыта от поисковиков)
favicon.svg             иконка во вкладке браузера
robots.txt, sitemap.xml для поисковиков
```

Как устроена страница: в HTML лежит только её контент внутри `<main id="page">`.
Шапку, окно, меню и футер вокруг него дорисовывает `site.js`.

## Частые действия

### Добавить новость на главную
В `data/news.json` добавь запись **в начало** списка:
```json
{ "date": "2026-10-01", "text": "Открыл раздел с промптами", "link": "/prompts/" },
```
`link` необязателен. Наклейка NEW! появляется сама на 14 дней.

### Открыть раздел
В `assets/js/site.js`, в списке `sections`, поменяй у раздела `ready: false` на `ready: true`.
Раздел появится в меню и пропадёт из блока «Что тут будет». Меню само появляется, когда открытых разделов больше одного.
Не забудь добавить раздел в `sitemap.xml`.

### Добавить промпт
Все промпты — в `prompts/prompts.json`, массив `prompts`. Поля:
- `id` — уникальный (`t80`, `photo-xxx`), `title`, `desc` — что получит человек;
- `format`: `text` или `photo`;
- `spheres` — список сфер (id из `spheres`), `tasks` — задачи; **папка в окне сферы — по первой задаче**;
- `attach` — что прикрепить (необязательно);
- `prompt`: `{ "ru": "...", "en": "..." }` — для фото только `en`;
- `lang` — рекомендуемый язык (`ru` / `en`), помечается ★;
- `fix` — подсказки «Если не получилось», `models` — где работает.

Поля для заполнения в тексте промпта: `[подсказка: пример]`. **В RU и EN версиях поля должны совпадать по порядку** — иначе форма собьётся при смене языка.
В английских версиях в конце добавляй `Reply in Russian.`

У каждой сферы в `spheres` есть `tags` — слова, по которым её ищут; у фото — `photoTags`. Поиск учитывает их, так что новые синонимы добавляй туда.

Иконки ярлыков — `assets/img/icons/*.png` (пиксель-арт 32×32, увеличенный в 4 раза). Имя иконки сферы = id сферы.

### Добавить рецепт
В `dough/recipes.json` добавь объект по образцу существующих. Поля:
- `name` — название, `cat` — категория (по ней группируется выпадающий список);
- `time`, `out` — время и выход (необязательно, просто для информации);
- **режим пересчёта** — одно из двух:
  - `"base": { "shape": "round", "d": 22 }` или `{ "shape": "rect", "w": 30, "h": 20 }` — пересчёт по форме; `"approx": true`, если размер формы подобран примерно;
  - `"yield": { "v": 8, "label": "Количество лавашей" }` — пересчёт по количеству;
- `items` — ингредиенты: `{ "n": "Мука", "v": 200, "u": "г" }`
  - `v` — число, диапазон `[2, 3]` или `null` (если количества нет, «по вкусу»);
  - `u` — единица: `г`, `мл`, `шт`, `ч. л.`, `ст. л.`, `стак.`, `щеп.`, `веточ.`;
  - `note` — пояснение мелким шрифтом, `alt` — замена: `{ "t": "или сухие", "v": 6, "u": "г" }`;
- `steps` — шаги приготовления, `notes` — советы (необязательно);
- `source` — источник: `{ "text": "Сайт", "url": "https://..." }` (необязательно).

В шагах не пиши количества ингредиентов: они не пересчитываются. Все количества — только в `items`.

### Сделать новый раздел
1. Скопируй папку `lab/` под новым именем, например `games/`.
2. В `games/index.html` поправь `<title>`, описание, `og:`-теги, `data-section="games"` и `data-title`.
3. Убери строку `<meta name="robots" content="noindex">`.
4. Добавь раздел в `sections` в `site.js`.

### Соцсети
Список в `assets/js/site.js`, блок `socials`. Из него строятся кнопки 88×31 в футере и пункты меню «Избранное».

### Меню окна, темы и окна-диалоги
- Пункты меню собираются в `site.js`, функция `buildMenu()`; что делает каждый пункт — объект `ACTIONS`.
- Темы: список `themes` в `site.js`, цвета — блоки `html[data-theme=...]` в `base.css`. Выбор посетителя запоминается в его браузере.
- Окно в стиле Win98 для своих страниц: `WMN.dialog({ title: 'Заголовок', icon: '💡', html: '<p>Текст</p>' })`.

### Счётчик посетителей
Число берётся из `data/counter.json`. Этот файл создаёт сервер (скрипт `/usr/local/bin/wmn-counter.py` раз в 2 минуты считает посетителей по логам nginx), в репозитории его нет — так и должно быть.
Один человек в сутки (по московскому времени) = один посетитель. IP-адреса не хранятся, только обезличенные хэши.

### Мем-генератор (раздел бота)
- Логика в `bot/meme.js` — это перенос функции `add_text_to_image()` из `impact_bot.py`: те же размеры шрифта, переносы, обводка и позиции. Если меняешь отрисовку в боте, поменяй и здесь.
- Фразы для «Случайной подписи» — `bot/phrases.json` (тот же формат, что в боте: перевод строки `\n` = текст сверху и снизу).
- Шрифты: Impact берётся с устройства посетителя (выкладывать его на сайт нельзя), если его нет — подставляется свободный Oswald Bold (`assets/fonts/meme-oswald.woff2`). Lobster — `assets/fonts/meme-lobster.woff2`.
- Картинка обрабатывается только в браузере и на сервер не отправляется. Ограничение — 20 МБ.
- **Никогда не клади в репозиторий `impact_bot.py`**: в нём токен бота, а репозиторий публичный.

### Игры
- Все игры — в `assets/js/games.js`. Файл подгружается, только когда посетитель открывает игру через меню «Игры».
- Пункты меню — в `site.js`, функция `buildMenu()`, блок «Игры». Каждая игра открывается в плавающем окне `WMN.window(...)`.
- Новая игра: функция в `games.js`, строчка в `window.GAMES = {...}` и пункт меню.
- Рекорды хранятся в браузере игрока (localStorage).
- После правки `games.js` увеличь номер версии в `site.js`: `games.js?v=2` → `?v=3`.

### Поменять дизайн
Цвета и шрифты — в самом начале `assets/css/base.css`, блок `:root`.

### Правило кэша
После правки `base.css`, `site.js` или `dough.js` увеличь номер версии в ссылках на них: `?v=1` → `?v=2` (во всех HTML-файлах).
Иначе у посетителей может остаться старая версия из кэша браузера.

## Проверить у себя на компьютере

Двойной клик по `index.html` не сработает: браузер не даст загрузить `.json`. Нужен мини-сервер.
В папке проекта открой терминал и выполни:
```
python -m http.server 8000
```
Открой в браузере `http://localhost:8000`. Остановить — `Ctrl+C`.

## Опубликовать

1. GitHub Desktop: **Summary** → **Commit to main** → **Push origin**.
2. На сервере: `git -C /var/www/wmn-lab pull` (или подождать минуту, если включено автообновление).

## Правила для нейросети

Если ты ИИ-ассистент и помогаешь с этим проектом:
- Владелец не программист. Давай полные файлы или точные фрагменты с указанием, куда вставить. Никаких «...» вместо кода.
- Не добавляй фреймворки, сборщики и npm-зависимости без явной просьбы.
- Общее (цвета, кнопки, меню, шапка, футер) — только в `base.css` и `site.js`. Не дублируй стили внутри страниц.
- Контент (промпты, рецепты, новости) — в `.json` и `.md`, а не в HTML.
- Все пути от корня сайта: `/assets/...`, `/prompts/...`.
- Сохраняй ретро-стиль: окно Win98, серые объёмные кнопки, WordArt, шрифты Times / Tahoma / Courier.
- Вёрстка должна нормально работать на телефоне.
- В репозитории не должно быть паролей, токенов и ключей: он публичный.
